Database Technologies I am studying emerging technologies,computer science related module. The application I chose is a simple online healthcare system.This system stores user data, messages and records. The system needs to store different types of data: User information name, email, ID Records text data like messages or reports Small files or logs activity history The data size can grow over time because more users will use the system and the system also needs fast access because users will search and update data often. The best structure for this system is a document store database NoSQL. an example is MongoDB this is because: data is flexible,not all records have the same format,easy to scale when data increases and its good for web applications The system will need simple queries like find user by ID or email get all records for one user update user information delete old data search records based on keywords so, I believe a document-based NoSQL database is the best choice because it is flexible and can handle changing data easily while its also suitable for modern applications that grow over time.
