In this report I will talk about a real example of a NoSQL database. I chose MongoDB because it is very popular and used by big companies like Netflix. Netflix is basically a platform where people watch movies and series online. It has millions of users so it needs to store a lot of data, this includes user profiles, what people watch and recommendations. This data is always changing so every time a user watches somthing or searches, new data is being made. Because of this the system needs a database which is fast and flexible and reliable too. MongoDB is a document database, this means it does not use tables like traditional SQL databases. Instead, it stores data in documents. This is useful because not all users have the same data, some of them watch more content than others, so their data is different. The database system they are using is called MongoDB. It is easy to use and works well with large amounts of data and it can also scale meaning it can support more users while the system is growing. I think MongoDB is a good solution for Netflix.The data is not fixed and changes a lot so a flexible database is better and also,users need fast results instead of waiting for minutes when they search or get recommendations. However, it has its own disadvantages like everything .NoSQL databases dont always have a strict structure so sometimes it can be harder to manage the data. Also SQL databases can be sometimes better, it depends. In general though, I think mongoDB is a good choice for this kind of application because it is flexible, simple and works well with big systems like Netflix so it could definitely work.
